
# API-контракты — Профессиональный навигатор

Статус: черновик для подготовки API-тестов.

## Общие правила

- Локальный адрес: `http://localhost:3000`
- Формат данных: JSON.
- Идентификатор сессии передаётся в заголовке `X-Session-ID`.
- Формат ошибок: `{"error": "описание ошибки"}`.

## 1. Выбор трека

**Метод:** POST  
**URL:** `/api/track/select`

Заголовок: `X-Session-ID: <UUID>`

Запрос:
```json
{
  "trackType": "explore"
}
```

Допустимые значения: `explore`, `interests`, `known_direction`.

Ответ — `200 OK`:
```json
{
  "sessionId": "fef8f990-9cd0-4c54-b0f3-94b0b12e1c4b",
  "trackType": "explore",
  "status": "selected"
}
```

Статусы: 200 — трек выбран; 400 — неверный UUID или JSON; 401 — отсутствует заголовок; 422 — ошибка валидации; 500 — внутренняя ошибка.

## 2. Отправка диагностики

**Метод:** POST  
**URL:** `/api/diagnostic/submit`

Заголовок: `X-Session-ID: <UUID>`

Запрос:
```json
{
  "answers": [
    {"questionId": "q1", "answer": "Мне нравится техника"},
    {"questionId": "q2", "answer": 5}
  ]
}
```

Ответ — `201 Created`:
```json
{
  "diagnosticId": "a12b34cd-1234-4567-8901-123456789abc",
  "savedAnswers": 2,
  "status": "submitted"
}
```

Статусы: 201 — ответы сохранены; 400 — неверный JSON; 401 — отсутствует заголовок; 404 — сессия не найдена; 422 — ошибка валидации; 500 — внутренняя ошибка.

## 3. Генерация рекомендаций

**Метод:** POST  
**URL:** `/api/recommendations/generate`

Заголовок: `X-Session-ID: <UUID>`

Сейчас это заглушка, генерация ИИ ещё не подключена.

Запрос:
```json
{}
```

Ответ — `202 Accepted`:
```json
{
  "status": "pending",
  "sessionId": "fef8f990-9cd0-4c54-b0f3-94b0b12e1c4b",
  "message": "Endpoint scaffold is ready. Recommendation generation will be connected to the catalog and GigaChat in week two."
}
```

Статусы: 202 — запрос принят; 400 — неверный UUID или JSON; 401 — отсутствует заголовок; 404 — сессия не найдена; 500 — внутренняя ошибка.

## 4. Сохранение обратной связи

**Метод:** POST  
**URL:** `/api/reflection`

Заголовок: `X-Session-ID: <UUID>`

Запрос:
```json
{
  "rating": "useful",
  "comment": "Рекомендации были полезны"
}
```

Допустимые оценки: `useful`, `unsure`, `not_useful`. Поля `recommendationId` и `comment` необязательны.

Ответ — `201 Created`:
```json
{
  "id": "b12b34cd-1234-4567-8901-123456789abc",
  "created_at": "2026-10-22T12:00:00.000Z",
  "status": "saved"
}
```

Статусы: 201 — сохранено; 400 — неверный JSON; 401 — отсутствует заголовок; 404 — сессия не найдена; 422 — ошибка валидации; 500 — внутренняя ошибка.

## 5. Получение списка профессий

**Метод:** GET  
**URL:** `/api/professions`

Тело запроса не требуется.

Пример ответа — `200 OK`:
```json
{
  "data": [
    {
      "id": "a12b34cd-1234-4567-8901-123456789abc",
      "external_id": "prof_001",
      "title": "Инженер-механик",
      "description": "Пример описания профессии"
    }
  ],
  "count": 1
}
```

Данные в примере иллюстративные.

Статусы: 200 — данные получены; 500 — внутренняя ошибка или ошибка БД.
